Projetos Desenvolvidos

Sistema de Gestão de Tarefas (Backend)

API REST desenvolvida em Java para gerenciamento eficiente de tarefas domésticas e produtividade. O sistema foca na organização lógica de responsabilidades e acompanhamento de métricas.

Principais Funcionalidades: CRUD completo com categorização e definição de prioridades. Associação de tarefas a responsáveis específicos. Geração de relatórios de produtividade (tarefas concluídas por pessoa).

MVP E-commerce: Pronto e Saudável todos os dias

Projeto Integrador desenvolvido em equipe (6 pessoas) para digitalizar o negócio de uma empreendedora real. A plataforma une venda de produtos (marmitas/kits) e contratação de serviços personalizados.

Destaques: Desenvolvimento de fluxo de compra completo (Catálogo, Carrinho e Checkout(Não Finalizado)). Sistema híbrido de e-commerce e agendamento de serviços. Foco na experiência do usuário (UX) para facilitar a gestão do negócio.

Simple Bank(Carteira Digital) em construção

Sistema de backend focado na lógica de uma Carteira Digital. O projeto implementa funcionalidades críticas de um banco simplificado, incluindo:

Transações P2P: Transferências instantâneas entre usuários e lojistas. Integridade (ACID): Garantia de consistência nas movimentações de saldo. Segurança: Implementação de Autenticação/Autorização e Gateway para pagamento de boletos.
